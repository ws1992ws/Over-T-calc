
# Overtime Calculator - Web Version

This is a browser-based Streamlit application.

## What it supports

- Start/end overtime period
- Sunday–Thursday weekdays
- Friday–Saturday weekends
- Multiple Basic Salary changes by effective date
- Multiple Transportation Allowance changes by effective date
- Vacation exclusions
- Intedab exclusions
- Public holidays remain included
- Day-by-day calculation
- Editable calculation constants
- Monthly summary
- Daily detailed results
- CSV downloads

## Run online with Streamlit Community Cloud

1. Create a free GitHub account if you do not already have one.
2. Create a new GitHub repository.
3. Upload:
   - app.py
   - requirements.txt
4. Go to https://share.streamlit.io/
5. Sign in with GitHub.
6. Click "Create app".
7. Select your repository and branch.
8. Set the main file path to:
   app.py
9. Deploy.

After deployment, Streamlit gives you a normal web link that you can open from your work laptop.

## Important privacy note

If you deploy this on Streamlit Community Cloud, the app is hosted on an external cloud service.
This version does not intentionally write entered salary information to a database or file, but the hosting environment is still external to your company.

If your employer considers salary information confidential, check your company's policy before entering real values.
